# Keyboard shortcuts

These are Luxtable's default keys. Single keys can be changed in Settings ▸ Shortcuts, and Settings ▸ Familiar switches to Lightroom Classic or Capture One keys. Press `?` in the app to see the keys in use.

## Navigate and view

| Keys | Does |
|---|---|
| `←` `→` `↑` `↓` | Previous / next photo, row up / down |
| `⇧` + arrows | Extend the selection |
| `⌘A` | Select all photos |
| `G` / `E` | Grid / viewer |
| `↩` | Open in the viewer |
| `F` or `Tab` | Hide panels |
| `B` | Hide the filmstrip |
| `⌃⌘=` / `⌃⌘-` | Larger / smaller filmstrip thumbnails |
| `⌃⌘F` | Full screen |
| `Space` | 100% at the cursor |
| `⌘+` / `⌘-` | Zoom in / out |
| `⌥⌘0` / `⌥⌘1` | Zoom to fit / actual size |
| `Y` | Before / after |
| `K` | Pin for compare |
| `S` | Expand / collapse stack (turns burst stacking on if it is off) |
| `←` `→` / `↩` / `Esc` | In the burst strip: previous / next frame, use as the stack's cover, close |
| `N` or `⌥⌘S` | Survey the selection |
| `J` or `⌥⌘J` | Clipping warning |
| `⌥⌘P` | Focus peaking |
| `⌥⌘L` / `⌥⌘N` | Loupe / navigator |
| `⇧S` | Soft proof on / off |
| `⌘0` | Show all photos |
| `⌘1` – `⌘5` | Show only that many stars |
| `⌥⌘[` / `⌥⌘]` | Move tool tab left / right |
| `Esc` | Back / close |
| `?` or `⌘/` | Keyboard cheat sheet |

## Cull

| Keys | Does |
|---|---|
| `1` – `5` | Rate 1–5 stars |
| `0` | Clear rating |
| `6` `7` `8` `9` `-` | Red, yellow, green, blue, purple label |
| `P` / `X` / `U` | Pick / reject / unflag |
| `⇧⌘K` | AI Cull |
| `⌘D` | New variant |
| `⌃⌘V` | Voice commands on / off |

## Edit

| Keys | Does |
|---|---|
| `C` | Crop tool |
| `R` | Straighten tool |
| `W` | White balance picker (scroll over its loupe to zoom) |
| `I` | Colour readout picker |
| `[` / `]` | Brush size |
| `⌘[` / `⌘]` | Rotate left / right |
| `⌘Z` / `⇧⌘Z` | Undo / redo |
| `⇧⌘C` | Copy adjustments |
| `⇧⌘V` | Apply to the selection |
| `⌥⌘V` | Copy from previous |
| `⌥⇧⌘M` | Match total exposures |
| `⇧A` or `⇧⌘A` | Auto Adjust |
| `⌥⌘A` | AI Optimize |
| `⌥⇧⌘A` | AI Changes |
| `⌘K` | Edit with words |
| `⇧⌘H` / `⇧⌘M` | Merge to HDR / panorama |
| `⇧⌘T` | Customize tools |

## Sessions and files

| Keys | Does |
|---|---|
| `⇧⌘N` | New session |
| `⌘O` | Open a session or folder |
| `⌥⌘W` | Close session |
| `⇧⌘L` | Browse all sessions in the Library |
| `⇧⌘I` | Import from card |
| `⌘E` | Export |
| `⌘F` | Find |
| `⌘,` | Settings |
