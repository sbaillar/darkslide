# AI Denoise model

`build-model.sh` builds the bundled NAFNet-SIDD-width32 float16 package. It uses `convert.py`, `nafnet.py` and the hash-locked `requirements.txt`. `LICENSE-NAFNet` is the upstream MIT licence.

Sources, pins, cache, reproducibility and runtime checks are in [docs/DENOISE_MODEL.md](../../docs/DENOISE_MODEL.md).
